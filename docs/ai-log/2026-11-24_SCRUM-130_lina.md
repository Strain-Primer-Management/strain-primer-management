# SCRUM-130 — Global search page across strains, plasmids and primers

- **Date:** 2026-11-24
- **Developer:** Lina
- **AI tool / model:** Claude Code / Claude Opus 5.5
- **PR:** #<number>

## What was asked
One search page that looks through strains, plasmids and primers at once and shows the
results grouped by kind, with a link to see all matches in each list.

## What the AI did
- Added the global search page, reusing the existing search of each kind and the home page's kind list.
- Limited each group to 10 results, newest first, with the total and a "see all" link keeping the text.
- Skipped kinds the user may not view, and gave a hint flag for searches under 2 characters.
- Documented the page's context for the frontend and wrote tests for grouping, short input, permissions and case.

## What a human checked
- Approved the plan, including the item shape, leaving out empty groups and the short-search rule.
