## What was asked
Let people sort the three lists by clicking a column, and keep the search, filters and sort
when they move to another page.

## What the AI did
- Added one shared helper that builds a list address with some parameters changed or removed.
- Added whitelisted sorting and safe paging (past the end gives the last page) to the shared list view.
- Gave each list its allowed sort columns and documented the new context for the frontend.
- Wrote tests for sorting both ways, unknown sort values, paging with search and out-of-range pages.
