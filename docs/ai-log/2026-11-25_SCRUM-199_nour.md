# SCRUM-199 — Auto logout after inactivity and after server restart

- **Date:** 2026-11-25
- **Developer:** Nour
- **AI tool / model:** Claude Code / Sonnet 5.5
- **PR:** pending

## What was asked
Log users out automatically after a period without requests, and make every login expire when the server or Docker restarts.

## What the AI did
- Set a 2-hour idle session timeout that restarts on every request.
- Added a command that deletes all sessions and made the start command run it.
- Added tests for the timeout, the expiry refresh and the command.

## What a human checked
- Chose the 2-hour value and reviewed the diff.

## Follow-ups
- The future production compose file must also run the command at start.
