# Security policy

This is a student course project, maintained on a best-effort basis.

**Found a vulnerability?** Please report it privately: open the repository's **Security** tab and choose
**Report a vulnerability** (GitHub private vulnerability reporting). Do not open a public issue or pull
request for it, and do not include real lab data, passwords or keys in your report.

We will read it and answer as soon as the team can. Fixes go through the normal pull request process.
